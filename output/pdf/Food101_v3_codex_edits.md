# Правки к отчёту Food-101 v3

## 1. Заменить один абзац на странице 2

В разделе «Почему ResNet-18 требует меньше вычислений» замени абзац от «Различие видно внутри повторяющегося блока» до «Такой вариант аналогичен ResNet-18» следующим текстом.

> Профиль ResNet-50 на ноутбуке показал, что среди свёрток больше всего времени в сумме заняли свёртки 1×1. Поэтому для ученика я выбрал архитектуру с двумя изменениями относительно учителя. Во-первых, число блоков в четырёх стадиях сократилось с [3, 4, 6, 3] до [2, 2, 2, 2]. Во-вторых, в каждом блоке вместо последовательности 1×1 → 3×3 → 1×1 используются две свёртки 3×3. Остаточные связи сохранились. Из 36 свёрток 1×1 остались три — по одной на каждом переходе между стадиями, где перед сложением нужно согласовать размеры тензоров. Так устроена выбранная для ученика ResNet-18. ResNet-50 я использовал как учителя при дистилляции.

## 2. Уточнить подпись на странице 1

Для существующей диаграммы «Операторы внутри сети» используй подпись «Свёртки (oneDNN)». Первое предложение под рисунком замени следующим:

> На ноутбуке PyTorch выполнял свёртки с помощью библиотеки oneDNN. На них пришлось 73,1% собственного времени CPU, измеренного профилировщиком внутри ResNet-50.

## 3. Предлагаемый график «Сколько времени занимают свёртки до и после смены архитектуры»

Если доступны обе трассы из `results/pilot`, поставь этот график на место правой панели на странице 1. Слева уже показаны этапы обработки JPEG. Для новой правой панели:

- Нарисуй три пары горизонтальных столбцов — для ядер 1×1, 3×3 и 7×7. Цветом обозначь модель: ResNet-50 или ResNet-18. У всех столбцов одна шкала от нуля, в миллисекундах.
- Для каждой модели сгруппируй вызовы свёртки по размеру ядра, сложи время внутри каждой группы и раздели на число профилированных проходов. Бери один уровень событий профилировщика, чтобы не посчитать дважды вызов PyTorch и вложенную операцию. Для обеих моделей используй замеры на одном Intel Core i7-1165G7, FP32, четыре потока, один снимок за проход.
- Подпись: «Среднее суммарное время свёрток каждого размера за один прямой проход. Обе сети измерены на одном Intel CPU». На самом графике подпиши длительности в мс.
- В README приведены доли времени всех свёрток для обеих сетей, но разбивку по размерам ядер нужно получить из трасс. Если её восстановить нельзя, оставь существующую диаграмму с уточнённой подписью из пункта 2.
